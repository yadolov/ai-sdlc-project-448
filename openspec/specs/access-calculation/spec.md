# Access Calculation Specification

## Purpose

Расчёт прав доступа сотрудника к сервисам на основе прямых и групповых разрешений.

## Requirements

### Requirement: Расчёт доступа по пользователю и сервису

Система **MUST** определять, имеет ли пользователь доступ к указанному сервису, и возвращать список источников, через которые этот доступ получен.

#### Scenario: Прямое разрешение

- **GIVEN** пользователь, которому выдано персональное разрешение на сервис
- **WHEN** выполняется запрос расчёта доступа к этому сервису
- **THEN** `granted` равно `true`
- **AND** `sources` содержит один элемент с `kind: "direct"` и соответствующим `permissionId`

#### Scenario: Разрешение через группу

- **GIVEN** пользователь, являющийся участником группы, которой выдано разрешение на сервис
- **WHEN** выполняется запрос расчёта доступа к этому сервису
- **THEN** `granted` равно `true`
- **AND** `sources` содержит один элемент с `kind: "group"`, `permissionId` разрешения и `groupId` группы

#### Scenario: Несколько источников доступа

- **GIVEN** пользователь с прямым разрешением и членством в группе, которой также выдано разрешение на тот же сервис
- **WHEN** выполняется запрос расчёта доступа к этому сервису
- **THEN** `granted` равно `true`
- **AND** `sources` содержит элементы: сначала прямой источник (`kind: "direct"`), затем групповые (`kind: "group"`)

#### Scenario: Несколько групп

- **GIVEN** пользователь, являющийся участником нескольких групп, которым выданы разрешения на сервис
- **WHEN** выполняется запрос расчёта доступа к этому сервису
- **THEN** `granted` равно `true`
- **AND** `sources` содержит все групповые источники в порядке следования разрешений в конфигурации

#### Scenario: Отсутствие разрешений

- **GIVEN** пользователь без прямого разрешения и без членства в группах с доступом к сервису
- **WHEN** выполняется запрос расчёта доступа к этому сервису
- **THEN** `granted` равно `false`
- **AND** `sources` пуст

#### Scenario: Чужие группы и сервисы

- **GIVEN** пользователь, запросивший доступ к несуществующему сервису
- **WHEN** выполняется запрос расчёта доступа
- **THEN** `granted` равно `false`
- **AND** `sources` пуст

#### Scenario: Временная независимость

- **GIVEN** конфигурация с разрешениями
- **WHEN** запрос расчёта выполняется в разные моменты времени (разные значения `at`)
- **THEN** результат остаётся одинаковым
- **AND** параметр `at` передаётся в функцию, но не влияет на вычисление
